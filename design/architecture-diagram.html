📝 Ключевые потоки данных:

  • Врач создаёт кейс: Client → Gateway → Case Service → PostgreSQL + S3 → Kafka (analysis.requests)
  • Анализ изображения: Kafka → Recognition Service → Vector DB → Kafka (analysis.results) → Case Service
  • Labs batch запрос: Labs API → Gateway → Labs Service → Kafka → Recognition → результат в Redis cache
  • Уведомления: Kafka (notifications) → Notifier → Email/Push/Webhook
