# Marketing site UI kit

A recreation of the Phenograph.com marketing surface. Open `index.html` to see the interactive assembly.

Components:
- `Nav.jsx` — top nav with product / evidence / for-clinicians / sign in
- `Hero.jsx` — hero with quiet headline, landmark visual, two CTAs
- `FeatureGrid.jsx` — three-column feature row (phenotyping, candidate ranking, workflow)
- `EvidenceBand.jsx` — horizontal strip of metrics / publication citations
- `Footer.jsx` — wordmark, nav columns, compliance line

Built for 1200px content width on a `#faf8f2` paper background.
